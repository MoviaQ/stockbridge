# NNNN: Tytuł decyzji

- **Status:** Proponowany | Przyjęty | Zastąpiony przez NNNN
- **Data:** RRRR-MM-DD

## Kontekst

Jaki problem wymaga decyzji? Jakie są ograniczenia? (2–5 zdań)

## Rozważane opcje

1. **Opcja A** – krótki opis. Plusy, minusy.
2. **Opcja B** – krótki opis. Plusy, minusy.

## Decyzja

Wybieramy opcję … ponieważ …

## Konsekwencje

- Co zyskujemy.
- **Co tracimy lub co kosztuje ta decyzja.**

## Jak sprawdzimy

Jaki test lub pomiar pokaże, że decyzja była dobra (lub zła).
